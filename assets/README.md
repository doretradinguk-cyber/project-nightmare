# Project Nightmare assets

Project-owned asset intake for the new game.

## New visual rule

The supplied artwork in `use these for pages/` is the visual source of truth for the new dashboard. Assets brought forward from the old engine repository are selected only when they support this new retrowave / industrial-horror direction.

**Do not copy the old dashboard, old page artwork, old jester effects, or old UI styling.**

## Curated texture sources

See `assets/textures/curated-textures.json` for the selected legacy texture sources and their intended roles.

Selected for the first pass:
- brushed concrete
- chipped concrete
- damaged plaster
- metal plate
- painted concrete
- plastered wall
- rock wall

Patterned terracotta is deliberately held back from the first pass.

The selected source packages are Git LFS binaries in the old repository. Their metadata has been catalogued, but binary transfer is not faked; the actual packages must be copied into this repository when the binary transfer path is available.
