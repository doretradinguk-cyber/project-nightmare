# Project Nightmare architecture

Primary repository: doretradinguk-cyber/project-nightmare.

The supplied PNG at the repository root is the visual source of truth. UI/background work preserves the artwork and builds effects around it.

## Runtime
- index.html: entry point
- css/nightmare.css: original dashboard styling for this repository
- script/pages.js: seven linked routes
- script/atmosphere.js: code-rain atmosphere
- script/eyes.js: cursor-follow eyes
- script/storage.js: browser knowledge store

## 3D roadmap
The sandbox is a foundation. The next implementation adds WebGL rendering, procedural mansion generation, lighting, collision and controller adapters.
